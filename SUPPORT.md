# Getting help

Kemlock Server is maintained by volunteers, so answers are best effort. These are the places to go.

| You want to | Go to |
| --- | --- |
| Ask how to install, configure or move from Vaultwarden | [GitHub Discussions](https://github.com/Arsslensoft/Kemlock-Server/discussions), after [docs/self-hosting.md](docs/self-hosting.md) |
| Share an idea or ask whether a feature fits | [GitHub Discussions](https://github.com/Arsslensoft/Kemlock-Server/discussions) |
| Report a bug | [A bug report](https://github.com/Arsslensoft/Kemlock-Server/issues/new?template=bug_report.yml) |
| Ask for a feature that is already agreed on | [A feature request](https://github.com/Arsslensoft/Kemlock-Server/issues/new?template=feature_request.yml) |
| Report a vulnerability | [A private security advisory](https://github.com/Arsslensoft/Kemlock-Server/security/advisories/new), never an issue or a discussion ([SECURITY.md](SECURITY.md)) |
| Report a conduct problem | [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |
| Fix something yourself | [CONTRIBUTING.md](CONTRIBUTING.md) |

## Before you ask

- Say which version you run, how you run it (Docker or the binary), which database it uses (SQLite,
  PostgreSQL or MySQL) and which client you use (the Kemlock app, a Bitwarden app or the web vault).
- Include the server's log around the problem, with secrets and addresses you don't want to share
  removed. Never post a vault, a master password, a recovery key or a setup code.
- Questions about the Kemlock app belong in the
  [Kemlock repository](https://github.com/Arsslensoft/Kemlock), and about Bitwarden apps with
  Bitwarden. Problems on a server run by someone else belong with that operator.
